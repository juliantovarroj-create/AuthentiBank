# AuthentiBank

## Descripción
AuthentiBank es un simulador de cajero automático desarrollado en Python. Permite autenticar usuarios mediante una tarjeta RFID y un PIN.

## Funcionalidades
- Consulta de saldo.
- Depósitos y retiros.
- Historial de movimientos.
- Cambio de PIN.
- Bloqueo después de tres intentos incorrectos.
- Manejo de cuentas de ahorros y cuentas corrientes.

## Conceptos de programación orientada a objetos
- Encapsulamiento.
- Herencia.
- Abstracción.
- Polimorfismo.

## Ejecución
Se necesita Python 3.10 o una versión posterior.

Ejecutar en la terminal:

```bash
python "bank cde.py"
```

Para ejecutar la demostración automática:

```bash
python "bank cde.py" demo
```
